Calendar

This is webpage is our calendar where you can have an expanded version of the calendar we have in our main dashboard. This webpage was created for you so you can can plan events, dates, deadlines, and many more things here. Simply tap a date (or rather box) in the calendar and you can finally add what you want.

Moreover, you can only add one event per date which is a slight issue on our part. However, I hope you are able to enjoy using this webpage. :D
